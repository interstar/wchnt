# Attic — historical development notes

These files were working specs while Schema, Methods, Import, Construction,
Target, and related features were being designed and implemented.

**They are not live documentation for someone learning WCHNT today.**

The user-facing language guide is [`../language.md`](../language.md).
Philosophy lives in [`../intro.md`](../intro.md). Compiler maintainers use
[`../plan.md`](../plan.md) and [`../development_guideline.md`](../development_guideline.md).

If prose here disagrees with the compiler or with `examples/`, trust the
compiler and the examples.
